# Projects

Ein Ordner je Projekt, angelegt aus [`core/process/project-template/`](../core/process/project-template/) nach [`core/process/project-bootstrap.md`](../core/process/project-bootstrap.md).

Projekte enthalten die konkrete Marke: Brief, Brand Foundation, Tokens mit Werten, Komponenten, Templates und Assets. Private oder vertrauliche Projekte werden per `.gitignore` aus dem öffentlichen Repository ausgeschlossen.

Das Pilotprojekt, an dem Core v1.0 entwickelt wurde, ist privat und deshalb hier nicht enthalten.

# DEMO · Radhof (fiktive Beispielmarke)

> **Dies ist keine reale Marke und keine reale Freigabe.** Radhof ist ein erfundener Fahrradservice, mit dem Core 1.1 (Brand Kit und Kanal-Starter) getestet wird. Name, Farben, Schriften, Logo, Adressen und Texte sind fiktiv und gelten **nur** in diesem Ordner. Sie sind **keine** Core-Defaults und dürfen nicht in reale Projekte übernommen werden.

- Quelle: [`brand-kit/brand-kit.json`](brand-kit/brand-kit.json) + [`tokens/`](tokens/) + [`assets/`](assets/)
- Erzeugen (aus dem Repository-Wurzelverzeichnis):
  `python3 core/brand-kit/generator/build_brand_kit.py demo/radhof-demo/brand-kit/brand-kit.json`
- Ergebnis: `brand-kit/dist/` (BRAND-KIT.html, BRAND-KIT.pdf, brand.css, channels/, QA-REPORT.md)

Der Kit-Status ist bewusst **ENTWURF** und enthält absichtlich offene Punkte (fehlendes Stempel-Logo, Illustration, Pinterest-Pin in Arbeitsfreigabe, fehlende Pinterest-URL), um die OFFEN-Kennzeichnung zu testen.

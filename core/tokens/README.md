# Tokens (Core)

> Core definiert die **Systematik**: Ebenen, Namen, Rollen, Pflicht-Tokens und Skalen. Die **Werte** (Farben, Schriften, Rundungen, Schatten …) setzt jedes Projekt in `projects/<p>/tokens/`.
> Ausnahme: Einige Skalen ohne Markenwirkung (Abstände, Zielgrößen, Ebenen, Breakpoints, Dauern) liefert Core als **überschreibbare Defaults** in [`defaults.tokens.json`](defaults.tokens.json).

| Datei | Inhalt |
|---|---|
| [architecture.md](architecture.md) | Ebenen (primitive → semantic → component), Vertrag, Dateiformat, Dateien im Projekt |
| [naming.md](naming.md) | Namensgrammatik, Kategorien, CSS-Variablen |
| [color.md](color.md) | Farbrollen, Pflicht-Rollen, Kontrast, Hell/Dunkel, Farbdokumentation für Print und Material |
| [typography.md](typography.md) | Typo-Rollen, Skalenmethode, Mindestwerte, Schriftwahl und Lizenzen |
| [spacing-sizing.md](spacing-sizing.md) | Abstandsraster, semantische Abstände, Größen, Zielgrößen, Dichte |
| [shape-elevation.md](shape-elevation.md) | Radius, Border, Shadow/Elevation, Opacity |
| [motion.md](motion.md) | Dauern, Kurven, reduzierte Bewegung |
| [layout.md](layout.md) | Breakpoints, Raster, Container, Z-Index |
| [contract.tokens.json](contract.tokens.json) | Pflicht-Tokens, die jedes Projekt mit Werten füllen muss |
| [defaults.tokens.json](defaults.tokens.json) | markenneutrale Default-Skalen (überschreibbar) |
